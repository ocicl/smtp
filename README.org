* smtp

An SMTP client and MIME message builder: STARTTLS and implicit TLS with
certificate verification, AUTH, PIPELINING, CHUNKING, SMTPUTF8 and DSN,
connection pooling, DKIM signing, and direct delivery with MX lookup.

Unrelated to cl-smtp; the system names do not overlap.
